# Before a future GitHub upload

No local changes should be pushed until the owner explicitly asks.

- The owner will edit names and entry numbers in reports before publishing. Original reference directories are ignored by Git for now.
- Place selected edited reports in `docs/` and selected photos in `images/`; keep the original files local.
- State the group context and the owner's actual contribution.
- Record HDL test results only after running the testbenches successfully.
- Clearly distinguish original work from later reconstruction and improvements.
- Add actual hardware settings only after verification.
- Choose a license only after deciding what rights can be granted for the shared work.
- Review the exact staged files; omit scratch files, build products, and unedited reference materials.
- Update the README status before publishing.
